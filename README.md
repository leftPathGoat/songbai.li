# songbai.li

Source code for Songbai Li's personal website.

Live site: https://songbai.li

## Stack

- Self-contained HTML and CSS
- No build step
- No JavaScript
- Hosted on Netlify

## Local preview

Run this from the repository root:

```bash
python3 -m http.server 8742
```

Then open http://localhost:8742.

## Deployment

The production site is deployed through the Netlify project named `songbaili`.
